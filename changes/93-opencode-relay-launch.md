section: The harness

- **An OpenCode relay answer says how to launch the reviewer.** Issue #93. On an OpenCode run, `launch_review_input` answering `relay: true` now also carries `launch`, `{agent, prompt}`: the built-in `general` sub-agent and the prompt `<!-- estigia:review name=<role> -->`, which the review relay plugin intercepts and replaces with the binary's exact prompt. The skill used to tell the host to name the reserved reviewer as the agent, which `estigia setup opencode` does not install, so OpenCode refused `Unknown agent`. The relayed reviewer runs with `general`'s write tools, a weaker seal than the CLI's tool-less reviewer; `docs/honesty.md` says so. The plugin also intercepts a sub-agent tool named `subagent`, beside `task` and `agent`, since a host that names its tool so was never relayed.
