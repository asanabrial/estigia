section: The harness

- **A Pi child is linked to its parent by its session header, not by pid.** The Pi gate extension decided parenthood by comparing process ids, so a child session run inside the parent's process was decided as an unrelated session and overwrote the exported root, mislinking later children. A session whose header names a `parentSession` is now a child of that session whatever its pid, and never exports a root; the pid comparison remains only for a separate process that inherited the variables and carries no header. `estigia doctor` gains a `pi-subagents` row that names the installed Pi subagent runners and warns on one whose children skip the gate; it installs nothing. The gate's decisions for a root session and for a separate-process child are unchanged.
