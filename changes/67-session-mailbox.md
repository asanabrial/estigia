section: The harness

- **`estigia sessions send` leaves a message in another session's mailbox, and the Claude Code, Codex and Pi hook points deliver it.** Issue #67, second slice. A `messages` table in `state.db` (schema 11) holds each message with its sender, recipient, text and delivery stamp; `estigia session deliver` takes the pending rows and stamps them in one statement; the `PreToolUse` hook (Claude Code and Codex) returns them as additional context beside its decision without changing it, and the generated Pi extension adds them as a prompt section at `before_agent_start`. The Claude Code and Codex `SessionStart` and `SessionEnd` hooks now also register and end the session in the registry. `estigia sessions` shows `waiting` and `undelivered_sent` per session, so a message nobody could take stays visible to its sender. OpenCode does not deliver, no runtime was driven live, and the accelerators are not built (`docs/sessions.md`, `docs/honesty.md`).
