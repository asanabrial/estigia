section: The harness

- **Pi gets a subagent runner with a live card.** Issue #72, first slice. `estigia setup pi` now also writes `estigia-agents.ts`, which registers the `estigia_subagent` tool and the `/estigia-agents` command. Each worker runs as its own `pi --mode rpc` process that inherits the environment, so its writes are decided by the gate as the parent's run; the runner refuses to launch a child when the parent session was not exported or the child did not load the gate extension. A card above the editor shows each worker's model, tokens, cost, elapsed time and last activity, and a refusal from the gate appears on it unchanged; `/estigia-agents stop` ends one worker or all of them. The gate's decisions and the loop extensions are unchanged. The full-screen view, steering, history and the `doctor` row naming another runner are not in this change.
