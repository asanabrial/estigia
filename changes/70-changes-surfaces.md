section: The harness

- **Pi shows a widget counting the checkouts that hold uncommitted work, and Claude Code gets an `/estigia-changes` command.** Issue #70, third slice. The Pi extension runs `estigia changes --json` at session start and after each settled turn and sets the `estigia-changes` widget through `ctx.ui.setWidget` to a count of the checkouts holding uncommitted work, with those git could not read counted apart; a clean repository clears it and an answer it cannot read shows `unknown`, never a count. `estigia setup claude-code` writes the `estigia-changes.md` slash command on every install, under the same ownership rule as the loop's commands: a file Estigia did not write is neither replaced nor removed. The OpenCode TUI plugin, a Claude Code status-line segment, a Codex notice of its own and a session-end notice are not built (`docs/honesty.md`).
