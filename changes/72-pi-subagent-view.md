section: The harness

- **The Pi subagent runner gets a full view, steering and history, and `doctor` names the other runners.** Issue #72, second slice. `/estigia-agents` (or `ctrl+alt+a`) opens an overlay listing running, finished and earlier children with each child's transcript; `s` stops one, `x` stops all after a confirmation, and `f` sends a follow-up to a running child. Each finished task is kept as an `estigia-agent` session entry through `appendEntry`, never sent to the model, and a resumed session lists them. The `pi-subagents` row of `estigia doctor` now names Estigia's own runner alone or beside another one, `estigia setup pi` says in a note when another runner is present and still installs its own, and `pi-config` flags a setting that excludes `estigia-agents.ts`. The gate's decisions and the loop extensions are unchanged; nothing here was run against a live Pi.
