section: The harness

- **A session is told about uncommitted work nobody holds, `done` and `release` name the files their own checkout still carries, and Pi gets `/estigia-changes`.** Issue #70. The `SessionStart` text every runtime receives now names the linked checkouts no run pointer holds that carry uncommitted files, with the branch, the file count and `estigia changes`; the read is bounded to three seconds and says how many checkouts it did not reach. `done` and `release` append the same kind of notice when the run's own checkout still holds uncommitted files; it is a notice and does not refuse, because `release` already keeps such a checkout. The Pi extension registers `/estigia-changes`, which draws `estigia changes` as a session entry that never reaches the model, like `/estigia-doctor`. The OpenCode, Claude Code and Codex surfaces, the Pi widget and a session-end notice are not built (`docs/honesty.md`).
